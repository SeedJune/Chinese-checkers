# 开发日志 · 2026-08-05

本次只重做视觉层，不改规则、交互状态机和 bot 搜索。目标不是给旧界面换一张背景，
而是建立一套能贯穿主菜单、棋盘、棋子、侧栏和提示层的国潮视觉语言。

## 视觉方向

- 宣纸底色承载大面积留白，青绿山水负责空间气氛；
- 墨青作为正文主色，朱砂负责选择与主操作，古金负责路径和棋盘细边；
- 六方棋子改为朱砂、石青、玉绿、藤紫、赭石、藤黄的矿物色系；
- 标题优先使用华文行楷，层级标题使用 Noto Serif SC，正文使用 Noto Sans SC；
- 字体查找兼容 Windows 的中文本地化字体名，缺失时自动降级。

两张专用背景位于 `assets/ui/`：

- `guochao-menu-v2.png`：左侧留白给设置笺页，右侧为青绿山水、亭桥和水墨流势；
- `guochao-game-v2.png`：中央保持安静以托住棋盘，竹影、金彩和水墨集中在边缘。

## 界面改造

主菜单变成宣纸画面上的浅色笺页，玩法卡片、人数卡片、玩家输入和规则统一使用
细边、低饱和纸色；主按钮使用朱砂。布局在默认模式、两人 bot 模式和三色模式下都
检查了最小窗口尺寸，避免 Windows 高 DPI 下裁掉内容。

棋盘改成淡青瓷色的三层细边结构，目标营地使用整片轻染，而不是十个醒目的色圈。
棋子使用抗锯齿的矿物釉石渐变，并保留纯 Tkinter 降级绘制。空孔、阴影、可走提示、
连跳路径和终点确认环都重新配色，减少与棋子颜色互相抢夺。

侧栏采用“行楷回合名 + 宋体栏目 + 黑体正文”的层级。确认走子是唯一朱砂主按钮；
其余操作退为纸色次按钮。鼠标交互保持不变：路线完成后再次点击当前落点即可确认，
终点会出现朱砂双环提示，回车和侧栏按钮仍可使用。

## 兼容与验证

- `python -m unittest -v`：169 项通过；
- 编译检查通过；
- UI 冒烟脚本覆盖菜单、经典局、三色局、连跳、动画、终局和 bot 回合；
- Pillow 写入 `requirements.txt`，用于正式的抗锯齿棋子；未安装时仍能启动纯 Tk 版本；

  `chinese-checkers`。

## 后续修整：新游戏与高 DPI 字体

对局侧栏右上角加入「新游戏」，点击后会取消尚未完成的 bot 搜索并返回开局配置页。

Windows 高缩放屏此前会先让 Tk 按 96 DPI 绘字，再把整个窗口作为位图放大；小号中文的
细笔画因此出现锯齿和发虚。现在应用在创建 Tk 根窗口前启用原生 DPI 感知，窗口、侧栏、
预览棋盘和背景图按设备比例同步缩放；说明文字从 11pt 提升到 12pt，并优先使用专门为
Windows ClearType 小字号优化的 Microsoft YaHei UI。行楷标题和宋体栏目保持不变。
